# Average Trading Strategy

## Task 1: Trading Strategy
- Implements a moving average strategy using 9-day & 18-day MAs.
- Run `Task1_TradingStrategy.m` with `ABNB.csv` in the same directory.

## Task 2: Decision Tree Classifier
- Builds a decision tree for financial decision-making.
- Run `Task2_DecisionTree.m` to generate & optimize the tree.

## Requirements
- MATLAB + Statistics Toolbox
- `ABNB.csv` (for Task 1)
